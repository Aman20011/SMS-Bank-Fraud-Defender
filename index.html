What people should do next

Check SMS header Use TRAI's Header Information Portal for sender-header lookup. Report fraud communication Use Sanchar Saathi Chakshu for suspected SMS, call, or WhatsApp fraud. Report suspect Cybercrime portal accepts suspicious SMS headers and numbers.

Why number-only checks are risky

Indian bank SMSes often use registered alphanumeric headers instead of normal 10-digit mobile numbers. A normal mobile number should usually be treated as unverified unless your bank explicitly publishes it as an official sender.

What production needs

Sync a trusted sender registry from TRAI header data, each bank's official communication pages, and reviewed user reports. Then run every check through a backend API with rate limits, audit logs, and privacy controls.

Safety rule

Never ask users to enter OTP, PIN, CVV, passwords, full card numbers, or full account numbers. A fraud-defense site becomes dangerous if it collects the same secrets scammers ask for.

This is an awareness prototype, not an official government or bank service.
